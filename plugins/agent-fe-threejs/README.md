# agent-fe-threejs

Optional add-on for 3D scenes in a web app: a rule for gating scenes, fallbacks, reduced motion and GPU cleanup, and an asset budget check for glTF/GLB models and textures.

**Why it helps.** A 3D scene can sink a page: it loads before anyone scrolls to it, never frees GPU
memory, ignores reduced motion, or ships a model far bigger than a phone can take. This plugin adds
the rule that gates the scene and a budget check for glTF/GLB assets.

## Install

<!-- install:start -->
1. **Add the marketplace** (once per machine). In a terminal:

   ```bash
   claude plugin marketplace add adhibuchori/agent-config-kit
   ```

   Inside Claude Code, `/plugin marketplace add adhibuchori/agent-config-kit` does the same.

2. **Install agent-fe-threejs.** Inside Claude Code:

   ```text
   /plugin install agent-core@agent-config-kit
   /plugin install agent-fe-threejs@agent-config-kit
   ```

   agent-fe-threejs is an add-on: install and set up your stack plugin first (or use agent-core alone), then add it. It depends on agent-core, so installing it installs agent-core too. If the new commands do not show up, restart Claude Code.

3. **Run setup in your repo:**

   ```text
   /agent-fe-threejs:setup
   ```

   Setup asks a few questions, one at a time, each with a recommended answer. Then it shows a dry
   run of every file it would write, and writes only when you reply **go**. Commit the new files
   together with `.claude/agent-config-kit.lock`: the lock is what turns the hooks on for everyone
   who clones the repo.

**Updates** reach you only when a plugin's version is bumped. Run
`claude plugin marketplace update agent-config-kit`, then
`claude plugin update agent-fe-threejs@agent-config-kit`, restart Claude Code, and run `/agent-fe-threejs:sync`
in each repo.
<!-- install:end -->

## Prerequisites

- agent-core (installed with it automatically) and everything agent-core needs: Claude Code, bash
  3.2+, git, **python3 3.8+** for setup, sync and the guards, jq optional.
- Node or bun to run `scripts/check/3d-budget.mjs` (no dependencies).

### Hooks

This plugin wires no hooks.

**What setup installs** (`/agent-fe-threejs:setup`): `.claude/rules/web/3d.md` (loads only
when a scene or asset file is touched), `scripts/check/3d-budget.mjs` with its seeded config
`scripts/check/3d-budget.json` (1.5 MB per model, 100,000 triangles, 512 KB and 2048 px per
texture, 2 MB per environment map), `docs/3d-skills.md`, and an allow rule for the budget check. The
draft prints a `gates.list` line and a `skillOverrides` snippet to add by hand.

## Configuration

`scripts/check/3d-budget.json`: the limits, and `exceptions` entries (one file, a higher limit, a
reason). Stale exceptions are warned about.

## Enabling and disabling

Installing a plugin changes nothing in a repo until that repo opts in (the lock written by setup,
or `.claude/agent-config.json`). To turn the plugin off:

```bash
claude plugin disable agent-fe-threejs@agent-config-kit --scope local   # this repo, for you only
claude plugin disable agent-fe-threejs@agent-config-kit                 # everywhere
claude plugin enable agent-fe-threejs@agent-config-kit                  # back on
```

agent-core keeps running. To remove the files setup installed, see [Uninstall](../../README.md#upgrade-and-uninstall).

## Privacy and data handling

- Its hooks (if any) run on your machine, read only their JSON input and files in your repo, and open
  no network connection. No telemetry, nothing downloaded at run time.
- Commands and agents read your repo; agents report and never edit.
- No third-party skill is vendored; `docs/3d-skills.md` shows how to add one by reference.

## Limitations

- An add-on: it pairs with a frontend stack plugin and asks no questions of its own.

## Troubleshooting

- **The budget check fails on one hero model.** Add an `exceptions` entry with a reason, rather
  than raising the limit for every file.

More in the [main FAQ](../../README.md#faq-and-troubleshooting).

## Reporting issues

- A hook refused something it should allow, or let something through: open a **Hook bug** issue
  with your OS, shell, bash, jq and python3 versions and the hook's JSON input.
- A security problem (for example a way past a guard): report it privately at
  <https://github.com/adhibuchori/agent-config-kit/security/advisories/new> (security contact: see
  [SECURITY.md](https://github.com/adhibuchori/agent-config-kit/blob/main/SECURITY.md)). Do not open
  a public issue.
- Anything else: a bug or feature issue on the repository.
