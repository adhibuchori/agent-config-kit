# agent-ai-fastapi

Guardrails and gates for a FastAPI service with LLM providers, managed with uv: the migration-guard hook, an AI-service reviewer, and the rules, pre-commit config and pull-request CI setup installs.

**Why it helps.** LLM services fail in ways a generic linter never sees: a provider called straight
from a route, a stream that never reports it finished, an error body built by hand, an Alembic
revision edited after it ran. This plugin writes those rules down, checks them in review and in the
gate, and refuses hand edits to generated migrations.

## Install

<!-- install:start -->
1. **Add the marketplace** (once per machine). In a terminal:

   ```bash
   claude plugin marketplace add adhibuchori/agent-config-kit
   ```

   Inside Claude Code, `/plugin marketplace add adhibuchori/agent-config-kit` does the same.

2. **Install agent-ai-fastapi.** Inside Claude Code:

   ```text
   /plugin install agent-core@agent-config-kit
   /plugin install agent-ai-fastapi@agent-config-kit
   ```

   agent-ai-fastapi depends on agent-core, so installing it installs agent-core too. If the new commands do not show up, restart Claude Code.

3. **Run setup in your repo:**

   ```text
   /agent-ai-fastapi:setup
   ```

   Setup asks a few questions, one at a time, each with a recommended answer. Then it shows a dry
   run of every file it would write, and writes only when you reply **go**. Commit the new files
   together with `.claude/agent-config-kit.lock`: the lock is what turns the hooks on for everyone
   who clones the repo.

**Updates** reach you only when a plugin's version is bumped. Run
`claude plugin marketplace update agent-config-kit`, then
`claude plugin update agent-ai-fastapi@agent-config-kit`, restart Claude Code, and run `/agent-ai-fastapi:sync`
in each repo.
<!-- install:end -->

## Prerequisites

- agent-core (installed with it automatically) and everything agent-core needs: Claude Code, bash
  3.2+, git, **python3 3.8+** for setup, sync and the guards, jq optional.
- uv, Python, and the tools the installed pre-commit config and gates run (ruff, mypy, pytest,
  vulture, import-linter).

### Hooks

| Hook | Event | Matcher | Data it reads | Block or warn | Timeout | Network |
| --- | --- | --- | --- | --- | --- | --- |
| [migration-guard](../../docs/agent-ai-fastapi/migration-guard.md) | PreToolUse | `Write`, `Edit`, `MultiEdit` and Serena's write tools | the target path; `migrationsDirs` | **blocks** (exit 2) | 10 s | no |

**What setup installs** (`/agent-ai-fastapi:setup`): backend and Python rules (FastAPI, providers,
performance, testing, coverage), anti-patterns, `.pre-commit-config.yaml`, `gates.list`, a vulture
whitelist, a pull-request-only CI caller of `ai-fastapi-quality-gate`, PR templates and, if the
service owns its schema, the pipeline example. `pyproject.toml` is never merged: the draft prints
its tool sections as a `by-hand` line.

## Configuration

`migrationsDirs` in `.claude/agent-config.json` (default includes `alembic/versions` and
`src/app/db/migrations/versions`). `"migrationsDirs": []` turns the guard off.

## Enabling and disabling

Installing a plugin changes nothing in a repo until that repo opts in (the lock written by setup,
or `.claude/agent-config.json`). To turn the plugin off:

```bash
claude plugin disable agent-ai-fastapi@agent-config-kit --scope local   # this repo, for you only
claude plugin disable agent-ai-fastapi@agent-config-kit                 # everywhere
claude plugin enable agent-ai-fastapi@agent-config-kit                  # back on
```

agent-core keeps running. To remove the files setup installed, see [Uninstall](../../README.md#upgrade-and-uninstall).

## Privacy and data handling

- Its hooks (if any) run on your machine, read only their JSON input and files in your repo, and open
  no network connection. No telemetry, nothing downloaded at run time.
- Commands and agents read your repo; agents report and never edit.

## Limitations

- No `package.json`, so no `unlock` alias: the unlock command is `./scripts/ops/unlock.sh env`.
- Answer `python` (or `both`) to agent-core's `language` question; its default recommendation is
  `typescript`.

## Troubleshooting

- **Setup installed TypeScript rules.** You took agent-core's default `language` answer; run
  `/agent-ai-fastapi:setup --answer language=python` in a fresh repo, or delete the rules.

More in the [main FAQ](../../README.md#faq-and-troubleshooting).

## Reporting issues

- A hook refused something it should allow, or let something through: open a **Hook bug** issue
  with your OS, shell, bash, jq and python3 versions and the hook's JSON input.
- A security problem (for example a way past a guard): report it privately at
  <https://github.com/adhibuchori/agent-config-kit/security/advisories/new> (security contact: see
  [SECURITY.md](https://github.com/adhibuchori/agent-config-kit/blob/main/SECURITY.md)). Do not open
  a public issue.
- Anything else: a bug or feature issue on the repository.
