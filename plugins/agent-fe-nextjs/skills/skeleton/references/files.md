# Skeleton files in the repo

The files the skeleton skill works from, by their path in the repo.

| File                             | Path                                                            |
| -------------------------------- | --------------------------------------------------------------- |
| The skeleton rules (S1–S16)      | `.claude/rules/web/skeletons.md`                                |
| The skeleton standard            | `.claude/docs/standards/skeletons.md`                           |
| The skeleton-height anti-pattern | `.claude/anti-patterns/skeleton-height-drifts-from-real-row.md` |

The rules load once a skeleton file is open. A repo without the rules file has not installed the
module; `SKILL.md` says what to do then.
