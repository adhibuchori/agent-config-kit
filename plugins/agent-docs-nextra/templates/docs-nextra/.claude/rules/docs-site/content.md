# Docs site content

A docs site fails in two quiet ways: a page states something the documented repository no longer
does, and a hand edit to a generated page disappears at the next regeneration. Neither breaks the
build.

## Generated or hand-written

Fill in the table for this site; a page it does not name is hand-written.

| Page               | Source                                                    |
| ------------------ | --------------------------------------------------------- |
| `<generated page>` | Generated by `docs:generate` from `<the source it reads>` |
| `<changelog page>` | Generated by `changelog:generate`, append-only            |

- A generated page changes at its source: edit the comment or commit it is built from, re-run the
  generator, and review the regenerated diff. The `generated-guard` hook (agent-docs-nextra)
  refuses hand edits to every path in `generatedPaths` (`.claude/agent-config.json`); keep that
  list and this table in step.
- If the writer preserves hand-written text below a marker, name the marker here. Only the text
  below it is yours to edit, and its page stays out of `generatedPaths`.
- Keep generated folders out of the formatter's scope. A formatter that rewrites them makes every
  page look stale to the generator's own comparison (`.claude/anti-patterns/INDEX.md`).

## Accuracy

- This site documents `<app-repo>`. A statement that is no longer true of it is a defect, not stale
  prose. Check the source before describing behaviour, and name the file you checked in the PR.
- `<a claim that must never drift>`: for example, which service owns sign-in.

## MDX

- Text generated from source comments is escaped when it is rendered, never trusted: collapse
  whitespace and escape `|`, `<`, `>` and `{` before a table cell, and `<` before tag-shaped prose.
  Both are correct source text that breaks the MDX build; a check at write time flags balanced
  multi-line code too, and a check that cries wolf gets switched off.
- Every page has its `_meta.js` entry. Internal links are root-relative and resolve, and an anchor
  matches the heading slug the site generates.
- A code block names its language, an image has `alt` text, and a diagram has a text summary.

## Static export

- `next.config.mjs` keeps `output: 'export'` and `images.unoptimized`. Nothing may need a server at
  request time: no route handler that reads the request, no middleware, no ISR, no `headers()`.
  Response headers come from the host, such as a `_headers` file in the assets directory.
- Everything the export contains is public: no secret in `content/`, `public/` or a `NEXT_PUBLIC_`
  variable.
- The Worker serves assets only: `wrangler.jsonc` has no `main`, and sets both `workers_dev` and
  `preview_urls` to `false`. Turning off one leaves the other address open.
- `nextra` and `nextra-theme-docs` move together, and only after reading
  `.claude/anti-patterns/nextra-zod-v4-bug.md`.
