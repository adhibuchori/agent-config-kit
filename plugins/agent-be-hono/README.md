# agent-be-hono

Guardrails and gates for a Bun + Hono + Drizzle API: the migration-guard hook, a backend reviewer, and the rules, checks and pull-request CI setup installs.

**Why it helps.** Most API regressions are structural: a handler that queries the database, a query
in a loop, a thrown string that skips the error contract, a migration edited by hand. This plugin
turns each into a rule, a lint error or a gate, and its reviewer cites the rule number.

## Install

<!-- install:start -->
1. **Add the marketplace** (once per machine). In a terminal:

   ```bash
   claude plugin marketplace add adhibuchori/agent-config-kit
   ```

   Inside Claude Code, `/plugin marketplace add adhibuchori/agent-config-kit` does the same.

2. **Install agent-be-hono.** Inside Claude Code:

   ```text
   /plugin install agent-core@agent-config-kit
   /plugin install agent-be-hono@agent-config-kit
   ```

   agent-be-hono depends on agent-core, so installing it installs agent-core too. If the new commands do not show up, restart Claude Code.

3. **Run setup in your repo:**

   ```text
   /agent-be-hono:setup
   ```

   Setup asks a few questions, one at a time, each with a recommended answer. Then it shows a dry
   run of every file it would write, and writes only when you reply **go**. Commit the new files
   together with `.claude/agent-config-kit.lock`: the lock is what turns the hooks on for everyone
   who clones the repo.

**Updates** reach you only when a plugin's version is bumped. Run
`claude plugin marketplace update agent-config-kit`, then
`claude plugin update agent-be-hono@agent-config-kit`, restart Claude Code, and run `/agent-be-hono:sync`
in each repo.
<!-- install:end -->

## Prerequisites

- agent-core (installed with it automatically) and everything agent-core needs: Claude Code, bash
  3.2+, git, **python3 3.8+** for setup, sync and the guards, jq optional.
- For the installed gates: bun, TypeScript, oxlint, oxfmt, knip, drizzle-kit and husky.

### Hooks

| Hook | Event | Matcher | Data it reads | Block or warn | Timeout | Network |
| --- | --- | --- | --- | --- | --- | --- |

**What setup installs** (`/agent-be-hono:setup`): backend rules (Hono, Drizzle, performance, testing,
error codes), anti-patterns, the check scripts (constants, coverage, migrations, index coverage,
module mocks) with `gates.list`, oxlint, oxfmt, knip and `bunfig.toml` config, `.husky/pre-commit`,
a pull-request-only CI caller of `be-hono-quality-gate`, PR templates, and package scripts such as
`db:generate`, `type-check` and `test:coverage`.

## Configuration

`migrationsDirs` in `.claude/agent-config.json` (default includes `drizzle` and
`src/db/migrations`); see [agent-core's table](../agent-core/README.md#configuration).

## Enabling and disabling

Installing a plugin changes nothing in a repo until that repo opts in (the lock written by setup,
or `.claude/agent-config.json`). To turn the plugin off:

```bash
claude plugin disable agent-be-hono@agent-config-kit --scope local   # this repo, for you only
claude plugin disable agent-be-hono@agent-config-kit                 # everywhere
claude plugin enable agent-be-hono@agent-config-kit                  # back on
```

agent-core keeps running. To remove the files setup installed, see [Uninstall](../../README.md#upgrade-and-uninstall).

## Privacy and data handling

- Its hooks (if any) run on your machine, read only their JSON input and files in your repo, and open
  no network connection. No telemetry, nothing downloaded at run time.
- Commands and agents read your repo; agents report and never edit.

## Limitations

- One primary stack per repo.
- The guard protects migration files from Claude's file tools; review migrations in the pull
  request like any other code.

## Troubleshooting

- **The guard never fires.** Your migrations live in a folder not in `migrationsDirs`; add it.

More in the [main FAQ](../../README.md#faq-and-troubleshooting).

## Reporting issues

- A hook refused something it should allow, or let something through: open a **Hook bug** issue
  with your OS, shell, bash, jq and python3 versions and the hook's JSON input.
- A security problem (for example a way past a guard): report it privately at
  <https://github.com/adhibuchori/agent-config-kit/security/advisories/new> (security contact: see
  [SECURITY.md](https://github.com/adhibuchori/agent-config-kit/blob/main/SECURITY.md)). Do not open
  a public issue.
- Anything else: a bug or feature issue on the repository.
