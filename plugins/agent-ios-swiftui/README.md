# agent-ios-swiftui

Guardrails and gates for a SwiftUI iOS app: the generated-guard hook, a standards reviewer and a
localization reviewer, two procedure skills, an accessibility audit command, and the rules, checks
and pull-request CI setup installs. Stable since 1.0.0: a rename or a removed rule, check or setting
is a major release.

**Why it helps.** Most app regressions are structural: a view that fetches and decides, a string
that never reaches the String Catalog, an error code the app was never told about, a build setting
hidden in the project file, a package nobody tests. This plugin turns each into a rule, a lint error
or a gate, keeps the app's logic in one Swift package that `swift test` covers file by file, and its
reviewers cite the rule number.

## Install

<!-- install:start -->
1. **Add the marketplace** (once per machine). In a terminal:

   ```bash
   claude plugin marketplace add adhibuchori/agent-config-kit
   ```

   Inside Claude Code, `/plugin marketplace add adhibuchori/agent-config-kit` does the same.

2. **Install agent-ios-swiftui.** Inside Claude Code:

   ```text
   /plugin install agent-core@agent-config-kit
   /plugin install agent-ios-swiftui@agent-config-kit
   ```

   agent-ios-swiftui depends on agent-core, so installing it installs agent-core too. If the new commands do not show up, restart Claude Code.

3. **Run setup in your repo:**

   ```text
   /agent-ios-swiftui:setup
   ```

   Setup asks a few questions, one at a time, each with a recommended answer. Then it shows a dry
   run of every file it would write, and writes only when you reply **go**. Commit the new files
   together with `.claude/agent-config-kit.lock`: the lock is what turns the hooks on for everyone
   who clones the repo.

**Updates** reach you only when a plugin's version is bumped. Run
`claude plugin marketplace update agent-config-kit`, then
`claude plugin update agent-ios-swiftui@agent-config-kit`, restart Claude Code, and run `/agent-ios-swiftui:sync`
in each repo.
<!-- install:end -->

## Prerequisites

- agent-core (installed with it automatically) and everything agent-core needs: Claude Code, bash
  3.2+, git, **python3 3.8+** for setup, sync and the guards, jq optional.
- For the installed gates, on a Mac: Xcode 27.0 (Swift 6.4), SwiftLint 0.65.1 (the version
  `.swiftlint.yml` pins) and Node 20 or newer. The pull-request gate's Linux job needs nothing of
  yours; its macOS job uses GitHub's `xcode-27` runner.
- Optional: Anthropic's `swift-lsp` plugin, for compile diagnostics after each edit.

### Hooks

| Hook | Event | Matcher | Data it reads | Block or warn | Timeout | Network |
| --- | --- | --- | --- | --- | --- | --- |

**What setup installs** (`/agent-ios-swiftui:setup`): a 33-rule `AGENTS.md` index and a short
`CLAUDE.md`, rules for the app target, the logic package, strings, tests, error codes and coverage,
12 anti-patterns, `Config/{Base,Debug,Release}.xcconfig`, `.swiftlint.yml` (strict, sizes in code
lines, custom rules for views, strings and the network), `.swift-format`, `.periphery.yml`, a
`Packages/AppCore` starter with `AppProblem` (the RFC 9457 problem the generated client decodes into)
and its tests, the generator settings, a privacy manifest, the check scripts with `gates.list`, the
named build and client scripts under `scripts/ios/`, `.githooks/pre-commit`, a pull-request-only CI
caller of `ios-swiftui-quality-gate`, PR templates and a CODEOWNERS starter. Optional: a DeepSeek
review of each pull request (`deepseek-review`, needs the `DEEPSEEK_API_KEY` secret), and the app's
half of the payload contract (`payload-encryption`, for a backend that seals bodies): `Payload*.swift`
in the APIClient target with their tests, `payload.config.json`, the shared vectors, the contract and
its rules. Setup never
creates or edits the Xcode project, never builds and never signs; the draft lists the steps only you
take.

## Configuration

`generatedPaths` in `.claude/agent-config.json` (setup seeds the generated client, the payload
registry and the spec copy); see [agent-core's table](../agent-core/README.md#configuration). The
layers of the logic package are in `scripts/check/package-graph.json`, the locales in
`scripts/check/i18n-catalog.json`, and, with `payload-encryption=yes`, the payload switch and
exemptions in `payload.config.json`.

## Enabling and disabling

Installing a plugin changes nothing in a repo until that repo opts in (the lock written by setup,
or `.claude/agent-config.json`). To turn the plugin off:

```bash
claude plugin disable agent-ios-swiftui@agent-config-kit --scope local   # this repo, for you only
claude plugin disable agent-ios-swiftui@agent-config-kit                 # everywhere
claude plugin enable agent-ios-swiftui@agent-config-kit                  # back on
```

agent-core keeps running. To remove the files setup installed, see [Uninstall](../../README.md#upgrade-and-uninstall).

## Privacy and data handling

- Its hook runs on your machine, reads only its JSON input and files in your repo, and opens no
  network connection. No telemetry, nothing downloaded at run time.
- Commands and agents read your repo; agents report and never edit. Nothing touches signing,
  provisioning or the login keychain.

## Limitations

- One primary stack per repo, and one `.xcodeproj` at the repo root.
- The spec copy is read as JSON; a backend that exports only YAML converts it first.
- `Text(String)` is not detectable by any tool: the reviewers read it.
- The macOS job's `xcode-27` label is a GitHub preview; set `CI_RUNNER_MACOS` to move it.

## Troubleshooting

- **SwiftLint exits 2 with "configuration specified version".** Your SwiftLint is not 0.65.1;
  install that version, or move the pin in `.swiftlint.yml` together with CI's.
- **The guard refuses an edit to the client.** Change the backend's spec, copy it again, and run
  `bash scripts/ios/api-client.sh`.

More in the [main FAQ](../../README.md#faq-and-troubleshooting).

## Reporting issues

- A hook refused something it should allow, or let something through: open a **Hook bug** issue
  with your OS, shell, bash, jq and python3 versions and the hook's JSON input.
- A security problem (for example a way past a guard): report it privately at
  <https://github.com/adhibuchori/agent-config-kit/security/advisories/new> (security contact: see
  [SECURITY.md](https://github.com/adhibuchori/agent-config-kit/blob/main/SECURITY.md)). Do not open
  a public issue.
- Anything else: a bug or feature issue on the repository.
